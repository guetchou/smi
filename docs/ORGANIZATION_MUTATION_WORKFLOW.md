# Workflow des mutations organisationnelles

Cycle : brouillon, soumis, approuve ou refuse, puis effectif.

Pour un agent existant, les changements de poste, departement, site ou superieur passent par ce workflow.

Regles : une seule mutation active par agent, date d'effet et motif obligatoires, auto-approbation interdite, responsable du departement cible recalcule, application planifiee, passage a corriger si la fiche a change, audit de chaque transition.

Interface : Organigramme > Departements > Mutations RH.
