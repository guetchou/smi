RÈGLES OBLIGATOIRES POUR L’AGENT IA

Avant de coder, tu dois toujours faire :

1. Lire l’existant.
2. Dire ce qui existe déjà.
3. Dire ce qui manque.
4. Dire les risques.
5. Dire les fichiers à modifier.
6. Dire les tests à faire.
7. Attendre validation avant de coder.

Interdictions :
- Ne pas pousser directement sur main.
- Ne pas mélanger plusieurs chantiers.
- Ne pas modifier dashboard.html massivement sans prévenir.
- Ne pas toucher à la production pour tester.
- Ne pas faire seulement le frontend sans sécurité backend.
- Ne pas créer un workflow sans notifications, audit, permissions et rollback.

Pour chaque workflow, vérifier :
- statuts
- transitions
- rôles / permissions
- routes backend
- boutons frontend
- notifications
- audit
- tests
- rollback
